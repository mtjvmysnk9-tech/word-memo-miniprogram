# 忆单词 WordMemo

基于微信小程序的英语单词记忆学习系统 —— 人工智能专业本科毕业设计。

一套艾宾浩斯间隔重复内核，三个客户端：电脑网页版、手机网页版、微信小程序。全部纯静态实现，不依赖后端与构建工具，学习数据只存在使用者本机。

在线地址：https://mtjvmysnk9-tech.github.io/word-memo-miniprogram/

## 要点

- 9 级记忆间隔（5 分钟 → 30 分钟 → 12 小时 → 1 / 2 / 4 / 7 / 15 / 30 天），翻卡自评四档，档位与下次到期时间自动写回
- 894 词三级词库（高考 / 四级 / 六级），后台可增删词条、CSV 批量导入、发布公告
- 测试自动组卷 4 种题型：看词选义、听音选词、听音拼写、例句填空；干扰项从全词表随机抽取
- 错词本自动进出：答错或自评模糊即入本，连续 2 次「记得 / 很熟」自动移出
- 统计：连续打卡、近 14 天学习量、40 天热力图、正确率、保持率、九级分布、每日专注时长
- 单一登录入口三种走法：注册 / 登录 / 游客登录；管理员密码由本人首次进入管理端时设定，代码与页面都不含默认口令

## 目录

| 目录 | 内容 |
| --- | --- |
| `index.html` | 站点首页，三端入口与说明 |
| `assets/` | 词库数据 `wordbank.js` + 共享内核 `core.js` |
| `web/` | 电脑网页版 |
| `m/` | 手机网页版（小程序同款界面） |
| `miniprogram/` | 微信小程序工程，8 个页面 + `app.json` + `utils/` |
| `docs/` | 系统设计说明（架构、数据模型、算法、流程、测试用例） |
| `tools/` | 小程序端逻辑自检脚本，`node tools/selfcheck.js` 跑 95 项断言 |

## 部署的两处差别

- **网页版**：推上 GitHub 开启 Pages 即可访问，电脑用 `/web/`、手机用 `/m/`，两端同一份词库与算法，数据各自存在本机浏览器。
- **小程序**：Pages 无法直接运行小程序，需用微信开发者工具导入 `miniprogram/`，AppID 选测试号，本地设置里取消「校验请求域名」（发音接口是第三方域名），再编译或真机预览。

## 数据说明

进入方式：普通使用者点「注册」自己设账号密码，已有账号点「登录」，不想注册就点「游客登录，先看看」。管理员切到「管理员」标签输密码，密码在首次进入管理端时由管理员本人设定，站点不展示也不内置。
密码在本机做非加密性哈希后保存，账号、学习记录、词库改动分别落在 `localStorage` / `wx.setStorageSync` 的独立键位；管理员页可一键复位。本系统不联网鉴权、不上传任何数据。

## 本地运行

- 网页版：克隆后直接双击 `web/index.html` 或 `m/index.html`，无需安装依赖。
- 小程序：微信开发者工具 → 导入项目 → 选择 `miniprogram/`。
