记忆算法：九级间隔 + 反馈调级

每个词记录 level / reps / lapses / dueAt。翻卡后按四档自评更新档位并写回下次到期时间： 「记得」升 1 级、「很熟」升 2 级并把间隔放大 1.3 倍、「有点模糊」降 1 级且间隔减半、「不认识」归零并 5 分钟后再见。

档位下次间隔典型场景
0 级5 分钟首次学习、自评「不认识」
1 级30 分钟当轮内二次确认
2 级12 小时当天晚间复习
3 级1 天次日到期
4 级2 天进入巩固期
5 级4 天—
6 级7 天周复习
7 级15 天—
8 级30 天视为已掌握（统计口径 level ≥ 4）

四种自动组卷题型

  • 看词选义：给单词，四选一释义
  • 听音选词：播放读音，选拼写
  • 听音拼写：播放读音，按首尾字母提示输入单词
  • 例句填空：挖掉目标词的例句，四选一

干扰项从全部词表随机抽取并排除同形词，答错即写回 FORGOT 并进错词本。

错词本自动进出

  • 自评「不认识 / 有点模糊」或测试答错 → 自动加入，记录错误次数与时间
  • 连续 2 次「记得 / 很熟」→ 自动移出，避免长期堆积

攻克页可直接以错词本为范围发起一轮复习或测试。

统计与留存

  • 连续打卡天数、近 14 天学习量柱图、40 天热力图
  • 正确率、保持率、九级分布、每日专注时长

按账号分桶保存于本机 localStorage / wx.setStorageSync，互不干扰。

微信小程序端

  1. 下载源码。把仓库 miniprogram/ 目录保存到本地（整个仓库克隆下来也可以）。
  2. 打开开发者工具。微信开发者工具 → 导入项目 → 目录选 miniprogram/，AppID 选「测试号」即可（工程里写的是 touristappid）。
  3. 关掉域名校验。详情 → 本地设置 → 取消「校验请求域名」（发音走 dict.youdao.com，属于第三方域名）。
  4. 编译运行。登录页输入 student / 123456，或点「游客进入」；用 admin / admin123 可进管理员页。
  5. 真机预览。点预览扫码，手机微信即可操作；底部标签栏为首页 / 学习 / 复习 / 测试 / 我的。

页面清单：pages/login、home、study、review、quiz、mine、stats、admin； 共享逻辑在 miniprogram/utils/core.js，其中存储层自动适配 wx.setStorageSync。

目录结构与架构

word-memo-miniprogram/
├─ index.html            本页面（站点首页）
├─ README.md             项目说明
├─ assets/
│  ├─ wordbank.js        词库数据（高考 / CET4 / CET6，894 词）
│  └─ core.js            共享内核：存储 · SRS · 账号 · 仓储 · 组卷 · 统计
├─ web/                  电脑网页版（index.html + app.js + styles.css）
├─ m/                    手机网页版（小程序同款 UI）
├─ miniprogram/          微信小程序工程（app.json + 8 个页面 + utils/）
├─ docs/系统设计说明.md   架构、数据模型、算法、流程与测试用例
└─ tools/selfcheck.js    小程序端自检脚本：node tools/selfcheck.js → 83 项断言

分层约定

  • 数据层 wordbank.js：只读词表，UMD 导出，三端同一份
  • 内核层 core.js：Store / SRS / Auth / Repo / Quiz / Stats / CMS / Catalog
  • 表现层：DOM（web、m）与 WXML（小程序）各自渲染，不写业务判断

换词库只改 wordbank.js；改记忆间隔只改 core.js 的 INTERVALS，三端同时生效。
